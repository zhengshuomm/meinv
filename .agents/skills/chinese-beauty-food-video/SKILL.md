## 🚀 视频生成执行引擎：Chrome CDP + Playwright 自动化控制 (最稳定、零封控风险 ⭐⭐⭐)

### 1. 核心原理
让自动化脚本直接复用你本地已经登录了 Ultra 账户的 Chrome 浏览器实例（`localhost:9222`）。
**既不需要逆向复杂的登录流程，也不需要 API Key，完全在官方真实前端环境下安全运行，彻底规避封控风险。**

### 2. 自动化执行管线
```
【连接 Chrome 9222 调试端口】➔ 【Playwright 接管会话】➔ 【自动校准 9:16 竖屏】
                                ➔ 【剪贴板注入起跑首帧 (Image-to-Video 锚点)】
                                ➔ 【注入携带完整外貌衣着锁定的纯中文提示词】➔ 【点击云端生成】
                                ➔ 【实时监听 0%~100% 进度】➔ 【精确抓取最新生成卡片下载 720p/1080p】
                                ➔ 【OpenCV 毫秒级提取末帧】➔ 【空镜重定向锚定】➔ 【连环生成下一镜】
```
