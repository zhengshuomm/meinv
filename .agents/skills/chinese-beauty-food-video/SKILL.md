# 中国地方美食美女短视频生成 Skill V2

## 1. Skill 目标

生成约 45 秒、9:16 竖屏的短视频：

**美女 + 中国地方美食 + 城市烟火气 + 强 Hook + 出镜女主亲口说自然中文台词。**

目标不是制作传统“探店流水账”，也不是单纯展示美女。

视频必须同时满足：
1. 前 3 秒有明显停留理由；
2. 食物是主要内容主体；
3. 女主人物全片保持一致；
4. 美食制作和吃法符合当地基本事实；
5. 每条视频有明确故事推进；
6. 旁白像真人，而不是连续 AI 金句；
7. 镜头之间自然连续，但不得为了连续性强行继承错误构图；
8. 最终视频长度优先控制在 42～48 秒；
9. 每个视频只重点介绍一种美食；
10. 每条视频必须有至少一个可被记住的独特点。

---

## 2. 核心原则

### 2.1 食物决定故事，禁止固定动作模板

严禁预设：
- 每条视频都咬第一口；
- 每条视频都烤；
- 每条视频都卷饼；
- 每条视频都喝汽水；
- 每条视频都从摊位拍到试吃；
- 每条视频都使用相同 8 镜。

必须根据当前美食自身特点动态决定动作。

例如：
* **武汉热干面**：捞面 → 加芝麻酱 → 快速拌开 → 萝卜丁 → 挑面 → 第一口。
* **上海生煎**：开锅 → 水汽 → 铲起 → 底部焦脆 → 咬开 → 汤汁。
* **北京烤鸭**：片鸭 → 脆皮 → 蘸甜面酱 → 放葱丝 → 卷饼 → 入口。
* **柳州螺蛳粉**：汤锅 → 腐竹 → 酸笋 → 辣油 → 嗦粉 → 味觉反差。
* **重庆火锅**：红汤沸腾 → 毛肚下锅 → 七上八下 → 蘸料 → 入口 → 辣感反应。

**固定的是叙事功能，不是具体动作。**

## 5. Stage 1：Food Research (地方美食事实校验)

在正式写脚本之前，必须先建立 `food_profile`，至少确认：
```json
{
  "canonical_name": "",
  "city": "",
  "province": "",
  "category": "",
  "core_ingredients": [],
  "signature_process": [],
  "signature_eating_method": [],
  "visual_highlights": [],
  "texture": [],
  "flavor": [],
  "cultural_context": [],
  "common_misconceptions": [],
  "must_not_show": []
}
```

目标回答：
- 这道食物真正来自哪里？最核心原料是什么？
- 最有画面感的制作步骤是什么？当地通常怎么吃？
- 什么细节最能证明“懂行”？哪些错误最容易被当地网友指出？
- 哪个视觉瞬间最值得拍？

如果事实存在争议：不要把争议内容写成绝对事实。优先表述为“当地常见的一种吃法是……”，而不是“正宗吃法只有这一种”。

## 6. Stage 2：Creative Angle (核心创意角度)

每条视频必须先确定一个核心角度，禁止千篇一律：
- **A. 反差**：看起来普通，入口完全超预期；
- **B. 城市性格**：一种美食如何代表一座城；
- **C. 感官体验**：脆、辣、鲜、烫、香、爆汁等核心痛点；
- **D. 地方规矩**：为什么当地人一定要这样吃；
- **E. 第一口体验**：外地人预期 vs 实际体验；
- **F. 小故事**：为什么当地人早上、深夜或特定时节特别爱吃；
- **G. 挑战/好奇**：闻起来让人退后，吃起来却停不下来。

禁止每条都使用“第一口直接把我吃沉默了”，一批视频中角度必须轮换。

---

## 7. Stage 3：Hook Generator (动态黄金钩子)

每条视频必须先生成至少 5 个候选 Hook（涵盖反常识、挑衅、好奇、感官、城市情绪等类型），选出最强版本。

**Hook 核心要求**：
- 时长：2～4 秒；
- 推荐字数：8～16 个汉字；
- 最多表达：**一个视觉事件 + 一个情绪反应 + 一句话**。

不要同时塞入五六个动作。

*好 Hook 示例*：
- 生煎：“等一下，这里面全是汤？”
- 热干面：“武汉人的早晨，真有点狠。”
- 臭豆腐：“闻着想走，吃完不想走。”
- 螺蛳粉：“这味道，为什么越吃越香？”
- 烤鸭：“最让我意外的，居然不是鸭肉。”

*禁止的 Hook*：美女大口咬下、汤汁爆炸、眼睛放大、镜头狂推、火焰升腾、同时狂说20多个字。

---

## 8. Stage 4：First-Person Dialogue Writer (出镜女主亲口说自然中文台词)

彻底废除传统第三人称画外音旁白，重构为**出镜美女主播面对镜头亲口说地道中文大白话**。

### 8.1 台词总字数控制
- 45 秒视频推荐：**120～155 个汉字**。
- 采用自然语速，不允许为了塞满信息而高速播报。
- 按时间段精准分配：
  - 0–4s：8～16 字（Hook，女主直视镜头亲口说抓人短句）
  - 4–10s：20～28 字（环境/背景，女主坐在店里自然向观众介绍）
  - 10–18s：25～32 字（制作细节，女主指着大厨介绍火候）
  - 18–27s：22～30 字（特色吃法/质感，女主亲手展示吃法秘诀）
  - 27–37s：24～30 字（真实品尝体验，咀嚼微停顿后直视镜头点评）
  - 37–45s：18～24 字（记忆金句与自信收尾，从容收尾）

### 8.2 台词先于视频生成与唇形匹配
完整第一人称台词 ➔ TTS 试读或实录 ➔ 获取精确音频波形与时长 ➔ 纯中文提示词中注入对镜头说话指令 ➔ 剪映智能对口型合流。

### 8.3 台词风格与去 AI 腔
台词应像一个真的吃过、懂一点、表达自然的真人食客，而不是广告播音腔或连珠炮 AI 金句。
- **金句限制**：每条视频**最多只允许 1～2 个明显 punch line**，其余句子必须是普通人具体、真实、接地气的自然味觉描述。
- **严禁滥用装腔与模板词汇**：全篇严禁出现“老饕”、“第一口直接……”、“天灵盖……”、“上头……”、“沦陷……”、“治好了所有内耗”、“这不是XX，是XX”等非正常人话的油腻表达，全篇必须是大白话、真实感受、接地气。

## 9. Stage 5：动态 Storyboard Planner (动态分镜规划)

默认生成 5～7 个镜头，**标准推荐 6 镜**（单镜 6～8 秒），彻底抛弃固定 8 镜硬套模式。

### 推荐 45 秒叙事结构：
1. **Shot 1 — Hook (0～4s)**：阻止划走，内容完全由当前食物特点决定；
2. **Shot 2 — Place / Context (4～10s)**：交代城市、环境氛围与为何值得吃，人物自然融入；
3. **Shot 3 — Signature Process (10～18s)**：表现当前食物最具辨识度的制作高潮（如热干面拌酱、生煎开锅、烤鸭片皮）；
4. **Shot 4 — Food Detail / Local Secret (18～27s)**：表现食物特别之处（火候、内部层次、酱汁、特色吃法）；
5. **Shot 5 — Taste (27～37s)**：女主真实品尝，微表情细腻自然，真实咀嚼与味觉分析，禁止夸张瞪眼；
6. **Shot 6 — Verdict / Ending (37～45s)**：提炼有深度、有讨论空间的观点或城市记忆，自然收尾。

---

## 10. Stage 6：人物与多维资产一致性系统

**核心理念：Reference > 长篇文字重复描述。**
文字不是身份 ID，不要每镜重复几十个外貌词浪费模型注意力。

### 10.1 优先级顺序
`character_reference_image` > `previous compatible frame` > `character identity concise description` > `negative prompt`

### 10.2 简明提示词规范
每镜出镜人物优先使用统一锚定语：
“严格保持与人物参考图相同的中国女性：相同面部身份、五官、发型、妆容、服装和饰品，不改变服装和饰品。”

### 10.3 注意力与权重平衡
画面视觉注意力必须严格维持：
- **食物**：40%
- **人物**：25%
- **动作**：20%
- **环境/摄影**：15%

美女负责流量入口、情绪与陪伴感，**美食才是真正的内容主体**。

## 11. Stage 7：Continuity Router (选择性连续与构图解耦)

**严禁无脑链式末帧继承！** 当构图或景别发生巨大跳跃（如从中景人物跳至俯拍锅底微距），强行继承末帧会严重污染画面并导致模型崩溃。

### 连续性决策逻辑 (Continuity Router)：
```python
if same_action_sequence and similar_composition:
    # 动作连续且构图相近：如夹起食物 -> 送入口中
    use_previous_last_frame()
elif character_is_focus:
    # 焦点回到人物：使用人物定妆参考图或上一人物正面末帧
    use_character_reference()
elif food_is_focus:
    # 焦点聚焦美食制作与细节：使用食物参考图或微距首帧
    use_food_reference()
elif environment_is_focus:
    # 焦点聚焦环境与烟火气：使用场景参考图
    use_scene_reference()
```

## 12. Stage 8：100% 纯中文电影级分镜提示词构建 (Pure Chinese Shot Prompt Builder)

> [!IMPORTANT]
> **视频生成提示词必须为 100% 纯中文，严禁英文机位词与洋腔提示词！**
> 生成提示词统一为 `prompt` 与 `prompt_cn`，严格遵循纯中文六段式电影级公式搭建：
> `【1. 景别运镜】 + 【2. 锁定主角固定发型与服装】 + 【3. 面对镜头亲口说话口型生动自然】 + 【4. 食物微距诱人细节与吃法动作】 + 【5. 市井暖色烟火气】 + 【6. 严苛中文负向约束】`

### 12.1 女主对镜头说话口型控制指令 (必须注入出镜说话分镜)
- **主述抓人指令 (Shot 1, Shot 2)**：
  `“女主直接抬眸直视摄像机镜头，眼神自信灵动，嘴唇自然饱满开合，清晰说出地道中文台词，口型动作生动真实，面部微表情随说话自然起伏。”`
- **品尝后点评指令 (Shot 5)**：
  `“女主自然咀嚼品尝刚出锅的美食，下颌肌肉自然律动，微顿半秒露出惊艳喜悦眼神，随即直接抬眸直视摄像机镜头，嘴唇自然饱满开合，清晰说出地道中文点评台词，神情真诚生动。”`
- **收尾金句指令 (Shot 6)**：
  `“女主品尝咽下美食后，坦荡从容直视摄像机镜头，眼神自信迷人，面带自然灿烂的微笑，嘴唇清晰自然开合，亲口说出记忆金句中文台词，语毕从容优雅轻微点头致意。”`

### 12.2 硬性物理规则：
1. **一个镜头只设置一个主要核心动作**，复杂行为必须拆镜；
2. **遵守物理真实性**：食物必须遵循真实重力、液体流动、真实尺寸与食材结构，严禁无故爆炸、喷射或拉丝；
3. **表情克制真实**：品尝后微表情为“停顿半秒 ➔ 轻微惊喜 ➔ 继续咀嚼 ➔ 自然评价”，拒绝夸张网红大瞪眼。

## 13. Stage 9 & 10：声音设计与方案 B 剪映智能对口型合流管线 (彻底消灭洋腔)

> [!CAUTION]
> **为什么 Veo 视频会有洋腔/听不懂？**
> Veo 是画面扩散模型而非中文语音模型，当提示词要求说话时，Veo 原生伴生音频只能幻觉出带欧美口音的伪中文乱语。
> **根本解法**：
> 1. Veo 仅负责生成高质量唇动与面部微表情画面；
> 2. 导出剪映时将视频轨音量强制设为 0（静音），彻底消除洋腔假杂音；
> 3. 台词语音由中国母语专业音色库（剪映 Pro 原生音色 / Edge-TTS）生成；
> 4. 剪映 Pro 中右键一键「智能对口型」，音画唇形 100% 精准咬字对齐！

1. **第一人称配音生成**：采用中国母语声学模型生成每镜独立台词音频，获取精确波形时长；
2. **方案 B 剪映自动化一键合流 (`export_to_jianying.py`)**：
   - 自动生成 9:16 (1080x1920) 剪映 Pro 工程草稿；
   - 自动化多轨合流：将视频片段放入 `MainVideo` 轨（强制静音），台词音频放入 `SpokenVoice` 轨，精准字幕放入 `Subtitles` 轨；
   - 在剪映 Pro 中选中视频片段，右键点击**「智能对口型」**，调用剪映官方中文唇形同步引擎，实现 100% 音画唇动精准对齐；
3. **声音分层架构**：`SpokenVoice (100%)` > `Food SFX (30~60%)` > `Ambient (10~30%)` > `BGM (8~20%)`；
4. **BGM 智能闪避**：台词出现时 BGM 自动下潜 ducking，品尝咀嚼瞬间留白突出真实 ASMR；
5. **精确字幕对齐**：字幕时间轴完全基于台词音频波形生成，居中靠底安全区，白字黑描边。

## 14. Stage 11 & 12：QA 验收与局部重试 (Selective Retry)

成片必须经过全维度验收：
- **Character QA**：人脸、发型、衣服、饰品全片高度一致；
- **Food QA**：食材、配方、吃法真实准确，无 AI 塑料感；
- **Hand QA**：手指数量正常，筷子/餐具接触真实；
- **Narrative QA**：删掉美女后仍是一条优质的美食视频；
- **Audio QA**：发音清晰、无错别字、BGM 不压人声。

**局部重试机制**：哪个镜头不合格就仅重生成该特定镜头，绝不因为一个镜头的瑕疵重做整条视频。

- 动态读取 `storyboard.json` 中的任意数量分镜；
- 遵循 Continuity Router 分发正确的起始参考帧；
- 保持稳健的浏览器 UI 自动化交互与状态监控；
- 支持单镜测试 (`--shot N`) 与整案动态生成 (`--all`)。

```bash
# 1. 动态生成项目立项与 100% 纯中文分镜配置 (例: 武汉热干面)
python3 .agents/skills/chinese-beauty-food-video/scripts/food_project_factory.py --food "热干面" --city "武汉" --character "沈昭"

# 2. 生成指定分镜视频 (例: Shot 1 黄金钩子)
```
