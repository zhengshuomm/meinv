# 美食短视频剧本台词打磨与大模型润色指南 (纯中文版)

本指南专用于在视频生成前，对初版台词进行极致打磨。通过结合 **OpenAI (ChatGPT)** 与 **DeepSeek** 的高阶文学推理与老饕语言表现力，以及通过 **Chrome 浏览器控制** 快速流转，产出节奏精准、食欲炸裂、零 AI 套话的“完美剧本”。

---

## 🎯 剧本完美度量化指标 (老饕六维标准)

1. **单镜严格字数卡点**：每镜台词控制在 **20 ~ 28 汉字**（净发音时长 3.5s ~ 4.2s），为镜头切换留出 0.35s 起音与 0.8s 收音留白，绝不超时抢拍；
2. **黄金 3 秒感官反常识钩子**：第 1 镜直击痛点，反常识、挑衅式或制造悬念（如“长得最不起眼的小摊，下手往往最狠”）；
3. **零 AI 假话套话**：100% 绝对封杀“绝绝子/YYDS/入口即化/非常美味/色香味俱全/深受喜爱/今天带大家品尝”，违者一律驳回；
4. **高密度微观感官动词**：使用“滋啦翻滚、油花飞溅、焦香扑面、裹满红油、琥珀剔透、酸辣直撞天灵盖、舌头先投降胃再起义”等高密度实体词；
5. **出镜女主专属人设与语气统一**：台词必须严格贴合选定女主的终身性格档案（如沈昭的犀利高冷、周敏仪的港岛微醺、赵子晴的川味泼辣），严禁人设漂移；
6. **试吃咀嚼瞬间音画留白 (ASMR)**：第 6 镜台词在送入口中瞬间嘎然而止，留出 2~3 秒纯粹的咀嚼清脆声或吸溜拟音。

## 🌐 Chrome 浏览器自动化控制与交互支持

本项目配套提供了 `scripts/script_refiner.py` 辅助脚本，支持以下 Chrome 联动模式：

1. **一键打开 Chrome 并推入剪贴板**：
   ```bash
   # 打开 ChatGPT 并将打磨提示词复制到剪贴板，直接在 Chrome 中 Command+V 粘贴
   python3 scripts/script_refiner.py --food "重庆火锅" --target openai --chrome
   
   # 打开 DeepSeek 并将打磨提示词复制到剪贴板
   python3 scripts/script_refiner.py --food "潮汕生腌" --target deepseek --chrome
   ```

2. **本地可视化打磨工作台 (HTML 桥接)**：
   脚本可自动在 Chrome 中打开专用的 `script_polish_bridge.html` 工作台，在浏览器中直观对比初稿、一键复制代码、粘贴大模型结果并一键生成最终视频工程配置。

3. **API 直接润色模式**（若配置了密钥环境变量）：
   ```bash
   python3 scripts/script_refiner.py --food "顺德鱼生" --api openai
   ```
