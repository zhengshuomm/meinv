# 美食短视频剧本台词打磨与大模型润色指南 (纯中文自然人话版)

本指南专用于在视频生成前，对初版台词进行极致打磨。通过结合 **OpenAI (ChatGPT)** 与 **DeepSeek** 的高阶文学推理与接地气的民间美食语言，以及通过 **Chrome 浏览器控制** 快速流转，产出节奏精准、食欲炸裂、说大白话人话、零 AI 套话的“完美剧本”。

---

## 🎯 剧本完美度量化指标 (爆款文案六维标准)

1. **全篇严格字数卡点**：全片 6 镜台词总字数严格控制在 **120 ~ 155 汉字**，单镜根据分镜时长合理分配（Shot 1 黄金钩子: 15~20字；Shot 2 城市背景: 20~27字；Shot 3 制作高潮: 22~28字；Shot 4 吃法细节: 22~28字；Shot 5 试吃点评: 24~29字；Shot 6 收尾金句: 20~25字），为镜头切换与起音收音预留自然留白，绝不抢拍；
2. **黄金 3 秒感官反常识钩子**：第 1 镜（0-4s）直击痛点，女主直视镜头亲口说出反常识、挑衅式或悬念短句（如“等一下！在兰州吃牛肉面，你可千万别叫拉面！”）；
3. **零 AI 假话装腔词**：100% 绝对封杀“老饕/绝绝子/YYDS/入口即化/直冲天灵盖/色香味俱全/深受喜爱/今天带大家品尝/治好所有内耗”等一切装腔作势与 AI 油腻套话，全篇必须是大白话、真感受、接地气；
4. **高密度微观感官动词**：依据菜品物理特性使用“滋啦冒油、小火星直窜、大笊篱几秒捞起、浓稠麻酱裹满、冰盘碎冰晶莹、小勺一挖如果冻”等具体扎实的动词与形容词；
5. **出镜女主专属人设与语气统一**：台词必须严格贴合选定女主的性格档案（如沈昭的干脆利落、周敏仪的港岛微醺、赵子晴的川味泼辣、宋晓芸的书卷温润），出镜说话分镜（Shot 1, 2, 5, 6）均为女主面对镜头亲口说话；
6. **试吃咀嚼瞬间音画留白 (ASMR)**：第 5 镜在送入口中咀嚼瞬间微顿半秒，眼神流露惊艳，留出清晰咀嚼拟音，随后直视镜头真诚点评。

## 🌐 Chrome 浏览器自动化控制与交互支持

本项目配套提供了 `scripts/script_refiner.py` 辅助脚本，支持以下 Chrome 联动模式：

1. **一键打开 Chrome 并推入剪贴板**：
   ```bash
   # 打开 ChatGPT 并将打磨提示词复制到剪贴板，直接在 Chrome 中 Command+V 粘贴
   python3 scripts/script_refiner.py --food "重庆火锅" --target openai --chrome
   
   # 打开 DeepSeek 并将打磨提示词复制到剪贴板
   python3 scripts/script_refiner.py --food "潮汕生腌" --target deepseek --chrome
   ```

2. **本地可视化打磨工作台 (HTML 桥接)**：
   脚本可自动在 Chrome 中打开专用的 `script_polish_bridge.html` 工作台，在浏览器中直观对比初稿、一键复制代码、粘贴大模型结果并一键生成最终视频工程配置。

3. **API 直接润色模式**（若配置了密钥环境变量）：
   ```bash
   python3 scripts/script_refiner.py --food "顺德鱼生" --api openai
   ```
